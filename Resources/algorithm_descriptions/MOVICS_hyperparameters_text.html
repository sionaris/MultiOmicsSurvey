Here, we run the MOVICS pipeline (see here) using the default parameters. When identifying the optimal number of clusters \(k\), we try for \(k \in \{2, \ldots, 10\}\). All algorithms are run with default parameters, apart from iClusterBayes where we set n.burnin = 1800 and n.draw = 1200, to reduce running times. The consensus multi-omic clustering algorithm is run for the optimal \(k\) only.
